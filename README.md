# BISC Union — backgrounds

Built from the same design guide as bisc.work: the brand palette, the
logo mark, and League Spartan.

## Zoom backgrounds (1920×1080)

| File | Use it when |
|---|---|
| `zoom-light.png` | Default. Off-white, logo upper-left. |
| `zoom-dark.png` | Dark green. Better if your room is bright or your camera washes out. |
| `zoom-simple.png` | Quietest — a slim green band across the top. Good when you are screen sharing and want less going on. |

Branding sits **upper-left** on purpose. The middle and lower-center are
where you appear, and Zoom puts your name badge bottom-left — anything
there gets covered.

**In Zoom:** Settings → Background & Effects → `+` → Add Image.

Your own preview shows the image mirrored, so text looks backwards to
you. Everyone else sees it the right way round. Leave "Mirror my video"
alone; it does not affect what others see.

## Desktop wallpapers

Two sizes of each. Use 2560×1440 for most laptops, 3840×2160 for a 4K
display.

| File | What it is |
|---|---|
| `desktop-light-*.png` | Off-white with a dark green band along the bottom. Icons stay readable. |
| `desktop-dark-*.png` | Dark green, logo and wordmark on the left. |
| `desktop-statement-*.png` | "You got the money. Now let's get the power." |

The top-left is kept clear on all three, because that is where desktop
icons land on both macOS and Windows.

## Logo files

Three transparent PNGs, cut from the artwork you supplied:

| File | What it is |
|---|---|
| `logo-full-transparent.png` | Mark, wordmark and tagline |
| `logo-lockup-transparent.png` | Mark and wordmark, no tagline |
| `logo-mark-transparent.png` | The mark on its own |

Transparent background, so they drop onto any color. On dark green,
put the logo on an off-white panel rather than recoloring it — the
dark green leaves and base would otherwise vanish.

## About the dots

The scattered circles are the same motif as the member count in the app —
one mark per person, in mixed colors. It comes from the branding group's
own note about the biscuit stack: irregular shapes mean individuality,
stacked together they hold each other up.
